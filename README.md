# testovoye-zadanie

Created in [T3 Code](https://t3.codes).

## Запуск

```sh
cp .env.example .env   # URL проекта и publishable-ключ (service_role сюда не кладём)
npm install
npm run dev
```

База: см. `supabase/README.md`. Проверка: `npm run build`.

## Демо-доступ
Логины и пароли тестовых пользователей (один постановщик, два исполнителя) передаются отдельно, в репозитории их нет.
