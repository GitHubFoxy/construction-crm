# Серверная часть CRM

Схема и права находятся в `migrations/`. Для применения к новому проекту выполните `supabase link --project-ref <project-ref>`, затем `supabase db push --remote`. Миграции не меняют настройки Auth: чтобы отключить открытую регистрацию, убедитесь, что в `config.toml` установлено `[auth] enable_signup = false`, проверьте изменения командой `supabase config diff` и примените их командой `supabase config push`. После этого повторно запустите `supabase config diff` и проверьте запрет регистрации через Auth API.

Пользователей создаёт администратор в Supabase Auth. Затем он добавляет их в `public.profiles` с тем же `id`, отображаемым именем и ролью `manager` или `worker`. Назначать задачи можно только пользователям с ролью `worker`. Приложение может читать имена и роли всех профилей, но не менять их.

Постановщик создаёт и редактирует объекты и задачи. Поля статуса, автора и даты создания нельзя менять через обычный API. Для смены статуса вызывается `transition_task(p_task_id, p_status, p_comment)`; база проверяет участника и переход, затем атомарно записывает историю. При создании задачи автоматически записывается начальный статус. Удаление выполняется функциями `delete_task(p_task_id)` и `delete_project(p_project_id)`: они скрывают записи, сохраняя задачи и историю в базе. Прямое удаление и изменение метки удаления через API запрещены; скрытые записи не видны в обычных запросах.

Статусы: `new` — новая, `in_progress` — в работе, `review` — на проверке, `accepted` — принята, `rework` — на доработке. Вызов с `rework` требует непустой комментарий. Исполнитель видит только свои задачи, их историю и связанные объекты.

Проверка прав и всех допустимых этапов выполняется в транзакции с откатом, без сохранения тестовых данных:

```sh
supabase db query --remote --file supabase/tests/security.sql --yes
```

Тест использует привилегированное подключение для временной подготовки пользователей, а затем переключается на роль `authenticated` и проверяет операции от имени каждого пользователя. Его нужно запускать только на тестовой базе.
